# Vintha Print Agent - Windows Desktop Installation Guide (100% Free)

### Quick Start (Shop Counter PC)
1. Double-click VinthaPrintAgentSetup.exe (or Start-VinthaPrintAgent.bat) to launch the Vintha Print Agent.
2. In your Vintha Print Web Dashboard (https://vintha-print.netlify.app/dashboard/printers), click "Add Print Computer" to get your 6-digit pairing code.
3. Enter the 6-digit code into the Agent and click "Pair Computer".
4. Select your counter printer (e.g. HP Smart Tank 580-590 series, Canon, Epson, Brother).
5. The dashboard will instantly show "Agent Online" with the selected printer.

### Auto-Start with Windows
- In the installer, keep "Start automatically when Windows boots" checked.
- Or right-click Install-VinthaService.ps1 and select "Run with PowerShell".
